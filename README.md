# gustavonutrisaas

Projeto estático pronto para publicação no Render.

## Arquivos principais
- `gr-nutri-app (5).html`: app principal
- `index.html`: entrada padrão para hospedagem (redireciona para o app)
- `render.yaml`: configuração do serviço estático no Render

## Publicação no Render
1. Conecte este repositório no Render.
2. Escolha **Blueprint** ou serviço **Static Site** usando a raiz do projeto.
3. Faça o deploy; o Render vai servir `index.html` automaticamente.
